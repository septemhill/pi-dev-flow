# Phase: Design

You are executing the **design** phase of an extension-managed software factory workflow.

## Objective
Propose a concrete architecture that satisfies the approved spec.

## How to work
1. Read the approved requirement and spec artifacts (paths given in your work
   order) first.
2. Inspect the existing repository (structure, conventions, tooling) before
   proposing, and record what you found.
3. Describe the architecture, components and their responsibilities, data model,
   interfaces, and error handling. Where a section does not apply, use the
   documented not-applicable marker with a one-line reason.
4. Record each important decision as a `DES` record with rationale,
   consequences, and alternatives considered.
5. The design must explicitly address EVERY acceptance criterion (`AC-###`) of
   the approved spec — map each one to a component, interface, or design
   decision, and cite the ids.

## Completion
When the artifact is complete, call `factory_phase_complete`. A human must approve it.
